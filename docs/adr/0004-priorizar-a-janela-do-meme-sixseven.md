# Priorizar a Janela do Meme Six-Seven em vez de longevidade de marca

O Aura Shift: Six Seven será um Jogo de Tendência assumidamente dependente do meme Six-Seven, e decisões de escopo priorizarão lançar enquanto essa referência ainda tiver força em vez de tentar construir uma marca evergreen. Aceitamos uma vida comercial curta; quando a tendência saturar, os aprendizados poderão alimentar um novo jogo separado, sem descaracterizar este produto para mantê-lo artificialmente relevante.
